# Kritzel WebSocket Server

A [Hocuspocus](https://tiptap.dev/docs/hocuspocus/introduction) WebSocket server for Kritzel real-time collaboration.

## Setup

```bash
npm install
```

## Development

```bash
npm run start:dev
```

The server starts on `ws://localhost:1234` by default. Set the `PORT` environment variable to change the port.

## Production

```bash
npm run build
npm start
```
