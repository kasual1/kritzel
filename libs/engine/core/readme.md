# Upmade Engine

This package contains the core engine that powers Upmade's framework-specific variants.

It is not intended as the primary entry point for application integration. Instead, use the framework wrapper that matches your stack:

- [@upmade/angular-engine](https://www.npmjs.com/package/@upmade/angular-engine)
- [@upmade/react-engine](https://www.npmjs.com/package/@upmade/react-engine)
- [@upmade/vue-engine](https://www.npmjs.com/package/@upmade/vue-engine)


Visit [upmade.io](https://upmade.io) for documentation and examples.
