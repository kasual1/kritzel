# Kritzel Stencil Core

This package contains the shared Stencil-based core that powers Kritzel's framework-specific variants.

It is not intended as the primary entry point for application integration. Instead, use the framework wrapper that matches your stack:

## Engine packages

- [@kritzel/angular-engine](https://www.npmjs.com/package/@kritzel/angular-engine)
- [@kritzel/react-engine](https://www.npmjs.com/package/@kritzel/react-engine)
- [@kritzel/vue-engine](https://www.npmjs.com/package/@kritzel/vue-engine)

## Editor packages

- [@kritzel/angular-editor](https://www.npmjs.com/package/@kritzel/angular-editor)
- [@kritzel/react-editor](https://www.npmjs.com/package/@kritzel/react-editor)
- [@kritzel/vue-editor](https://www.npmjs.com/package/@kritzel/vue-editor)
