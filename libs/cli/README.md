# @kritzel/cli (deprecated)

`@kritzel/cli` is deprecated and no longer installs Kritzel. Running it only prints the instructions below.

Install the editor package for your framework directly:

```bash
npm install @kritzel/angular-editor   # Angular
npm install @kritzel/react-editor     # React
npm install @kritzel/vue-editor       # Vue
```

Then follow the quick start for your framework:

- [Angular](https://kritzel.io/docs/angular/getting-started/quick-start)
- [React](https://kritzel.io/docs/react/getting-started/quick-start)
- [Vue](https://kritzel.io/docs/vue/getting-started/quick-start)
