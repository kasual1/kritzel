# Theming

The `KritzelTheme` interface groups all CSS custom property overrides supported by
Kritzel. The complete property catalog is maintained in the Angular API reference,
which is framework-independent and applies to Vue as well:

- [Complete KritzelTheme property reference](/docs/angular/api-reference/theming)

All theme values are strings, so colors, dimensions, font declarations, shadows, and
other valid CSS values can be supplied. Use the Vue theme APIs documented in
[Themes](../customization/themes.md) to apply a theme in a Vue application.
