Here you find general information about the project: @.github/instructions/general.instructions.md .
We want the users to be able to use the kritzel-library alongside their favorite llm, coding agent or videcoding tool in order to create their custom infinite canvas experiences. It should be easy and realiable for coding agents to intereact with the @libs/kritzel-stencil/src/components/core/kritzel-editor/kritzel-editor.tsx or the @libs/kritzel-stencil/src/components/core/kritzel-engine/kritzel-engine.tsx . Hence I want you to take a look at the public API as well as the documentation under ./website/docs/vue and derive a clean an solid skill infrastructure. It is okay to devide it into multiple files to keep things well structured. Also make sure to derive very geralized rules about how to interact with the kritzel-editor or the kritzel-engine in Vue. Code examples can be found in the vue demo project.
