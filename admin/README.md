# Project Administration & Management (`admin/`)

This directory contains resources, records, and media for managing, maintaining, and operating the Kritzel project.

## Contents

- **[`services.md`](./services.md)**: Centralized registry of third-party platforms, websites, and account identifiers (AWS, Formspree, GitHub, NPM, etc.).
- **[`marketing/screenshots/`](./marketing/screenshots/)**: Product screenshots, feature captures, and marketing imagery.

## Security Notice

- **Never commit credentials, private keys, or secret tokens into this repository.**
- Local notes matching `*.local.*` (e.g. `admin/credentials.local.md`) and the `admin/secrets/` directory are excluded from Git via `.gitignore`.
